Hard Constraints (Strict Enforced)

Hard constraints must be 100% satisfied for a timetable to be deemed feasible:

  • No Teacher Clashes: Faculty cannot teach > 1 class simultaneously.
  • No Section Clashes: Class sections cannot have overlapping periods.
  • No Room / Lab Overlaps: Physical rooms host at most 1 class per time slot.
  • Room Capacity Check: Room capacity must accommodate section strength.
  • Faculty & Room Availability: Respects configured availability days (Monday to Saturday).
  • Flexible Day-Wise & Period-Wise Scheduling: Specific activity days (e.g. Wednesday Library, Friday Lab) with automatic clash-free period selection.
  • Continuous Multi-Hour Classes: Multi-period subjects scheduled as consecutive uninterrupted blocks in the same room.
  • Resource Type Compatibility: Specific venue matching for Classrooms, Laboratories, and Central Library.
  • Weekly Requirement Fulfillment: All required weekly lectures/labs are placed.
